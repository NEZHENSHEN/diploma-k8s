# Service
Объект Kubernetes, который представляет стабильную сетевую точку доступа к набору backend-эндпоинтов (обычно pod)
## Своими словами
Service решает по 3 проблемы:
1) IP-адреса подов непостоянны. Deployment может создать новый под.
2) Несколько реплик (может быть 3 пода у сервиса). Как распределять запросы между репликами?
3) Обнаружение сервисов. Сервис должен узнавать IP адреса всех подов?
Service обеспечивает стабильную точку обращения, а k8s поддерживает актуальный набор доступных приложений.
