# Архитектура k8s
## Что это

K8s работает на группе серверов, которая называется кластер. Кластер моно представить как компанию в которой есть:
* Офис управления - сервера, которые принимают решения
* Рабочие цеха - серверы, где запускаются контейнеры
В K8s эти части называются:
* Control Plane (управление) - управляющие серверы
* Worker Nodes (рабочие узлы) - серверы для контейнеров
![[K8s Architecture]]
Control plane состоит из нескольких компонентов. Каждый выполняет свою роль:
* Api Server - главный вход. Все запросы проходят через него (команды k8s, компоненты k8s общаются друг с другом через api server)
* Etcd - память кластера (БД, где хранится вся информация: например какие контейнеры должны работать, на каких серверах они запущены, все настройки и конфигурации)
* Scheduler - распределитель задач (решает, на каком сервере запустить контейнер. Как менеджер распределяющий задачи)
* Controller Manager - набор программ, которые следят, чтобы все работало как надо (Например если контейнер упал - запустить новый, нужно 3 копии приложения - поддерживать ровно 3, сервер не отвечает - перенести контейнеры на другой)

Worker Node - где собственно работают контейнеры в нём есть свои компоненты:
* Kubelet - (как местный управляющий) программа на каждом рабочем сервере, которая
	* Получает команды от Control Plane
	* Запускает и останавливает контейнеры
	* Следит за их состоянием
	* Докладывает наверх, что происходит
* kube-proxy - (сетевой помощник), настраивает сеть, чтобы контейнеры могли общаться:
	* Направляет сетевой трафик к нужным контейнерам
	* Распределяет нагрузку между копиями приложения
* Container Runtime - запускает контейнеры. Программа, которая умеет работать с контейнерами (чаще всего containerd).

## Как работает вместе на примере
1. "Хочу запустить контейнер с nginx"
2. Команда приходит в API Server
3. API Server сохраняет в etcd: "Нужен контейнер nginx"
4. Scheduler видит: "Новый контейнер без места!"
5. Scheduler выбирает сервер: "Пусть будет Node-2"
6. API Server сохраняет решение в etcd
7. kubelet на Node-2 видит "Мне нужно запустить nginx"
8. kubelet запускает контейнер
9. Контейнер работает
